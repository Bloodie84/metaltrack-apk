# Metal Track — mises à jour à distance

Cette branche porte les mises à jour du code de l'application Metal Track,
lues par l'application elle-même à chaque ouverture. Ce n'est pas une
application installable : pour installer Metal Track, voir la branche `main`.

- `<version>/manifest.json` : la dernière mise à jour publiée pour cette version
- `<version>/<id>/` : ses fichiers
