# Metal Track — APK Android

Dépôt de distribution. Il ne contient **que les APK compilés**, aucun code source.

## Installer

1. Ouvrir la [dernière version](https://github.com/Bloodie84/metaltrack-apk/releases/latest)
2. Télécharger le fichier `.apk`
3. Autoriser l'installation depuis cette source si Android le demande
4. Installer

Aucun compte GitHub n'est nécessaire.

## À savoir

- **Android uniquement**, processeurs arm64 (tous les téléphones récents).
- L'application est signée avec une clé de développement : Android affichera un
  avertissement à l'installation, c'est normal hors Play Store.
- Metal Track fonctionne **hors réseau** pour le GPS, l'enregistrement des sorties
  et les trouvailles. Seul l'affichage des fonds de carte demande une connexion.
- Pensez à désactiver l'optimisation de batterie pour Metal Track, sans quoi
  certains téléphones (Xiaomi, Huawei, Samsung) coupent le suivi GPS quand
  l'écran s'éteint.

## Cartographie

Fonds et calques fournis par la Géoplateforme IGN : orthophotos, Plan IGN v2,
ombrage du MNT LiDAR HD, et carte de Cassini (IGN / Archives nationales).
